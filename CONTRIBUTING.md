# Contributing to Kampung Coin

Thank you for your interest in contributing to Kampung Coin! This is a learning project, and feedback from the community is valuable.

## How to Contribute

### Reporting Bugs

If you find a bug, please open an issue with:
- Clear description of the bug
- Steps to reproduce
- Expected vs actual behavior
- Your environment (Node version, network, etc.)

### Suggesting Enhancements

Feature suggestions are welcome! Please open an issue with:
- Clear description of the feature
- Use case and benefits
- Any implementation ideas you have

### Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Add tests for your changes
5. Ensure all tests pass (`npm test`)
6. Commit your changes (`git commit -m 'Add amazing feature'`)
7. Push to the branch (`git push origin feature/amazing-feature`)
8. Open a Pull Request

### Coding Standards

- Follow Solidity style guide
- Comment complex logic
- Add tests for new functionality
- Keep functions small and focused
- Use OpenZeppelin libraries when possible

### Testing

All code changes must include tests:
```bash
npm test
```

Ensure tests pass before submitting PR.

### Documentation

Update documentation if you:
- Add new features
- Change existing functionality
- Modify deployment process

## Code of Conduct

- Be respectful and constructive
- Welcome newcomers
- Focus on what's best for the project
- Show empathy towards others

## Questions?

Feel free to open an issue for any questions about contributing!
